这里保存有意纳入版本控制的真实测量审核快照。原始推理报告、日志、临时语料和数据库仍位于外置构建目录，不能把这些运行产物放入源码树。快照保存逐查询结果、语料和模型身份、原始报告 SHA-256、阈值选择过程及失败原因。

失败主要表现为部分不相关文档查询仍返回雨景视频、雨声等媒体，以及若干代码正例被代码门槛拒绝。完整逐查询结果保留在快照中。此结论来自受控作者标注语料，不能视为开放领域独立盲标研究。

不能在读取这份 holdout 结果后重新选择阈值、移动主题或修改标签，再把同一组宣称为首次独立验证。后续若改变拟合策略或检索行为，需要预先固定新的独立验证主题，并保留本次失败快照。

复核使用外置目录中的 `raw-relevance.json` 与 `policy.json`。快照是当时 `policy.json` 的逐字节副本，`reportSha256` 绑定原始采样文件。运行 `calibrate_relevance.py` 可以从相同原始文件重现该结果，失败时命令返回非零状态且不覆盖已有策略头文件。

## 已观察数据的有限机制研究，未形成生产策略

后续仅在全部已观察的 318 条正例和 176 条无答案查询上进行有限开发对照，没有创建第三套独立 holdout。V2 的 5% 是内部训练约束，用户要求始终为总体召回至少 90%、分组至少 80%、无答案误返回至多 10%。下面四个组合已将训练上限也设为 10%，不能把失败仅归因于额外的 5% 约束。

`absolute` 为绝对门槛，`contrast` 为固定的代码不同文件对比分数机制。`intent` 为冻结的格式意图兼容规则，仅根据查询文本和显式代码空间推断意图，再以候选的真实通道与容器类型判断兼容性。下表记录三折 OOF，全部属于已观察 development 研究：

| 组合 | OOF 正例 Recall@10 | OOF 无答案误返回率 | OOF 环境声 Recall@10 | 结果 |
|---|---:|---:|---:|---|
| absolute | 298/318，93.71% | 19/176，10.80% | 10/14，71.43% | 失败 |
| contrast | 303/318，95.28% | 22/176，12.50% | 10/14，71.43% | 失败 |
| absolute + intent | 299/318，94.03% | 18/176，10.23% | 10/14，71.43% | 失败 |
| contrast + intent | 305/318，95.91% | 21/176，11.93% | 10/14，71.43% | 失败 |

四个组合都未满足环境声分组及无答案门槛。固定意图规则分别减少一条无答案误返回，但不能解决主题相关性或环境声区分问题。部分代码召回提高和全部已观察数据上的可达拟合点均不构成验收证据，精确候选上的研究也不能替代有界 ANN 生产检索验证。这些有限实验不证明所有可能方法都不可行。

本次有限比较已结束，摘要为源码树外 `relevance-strategy-development/bounded-mechanism-comparison-final-summary.json`，SHA-256 为 `ddbe3570127bf719c232260e63a187d4de4c2227f514acee846093a5f5be8807`。详细外置报告为 `all-seen-fixed-two-mechanism-cv-training10.json` 和 `all-seen-fixed-two-mechanism-intent-cv-training10.json`。它们没有复制到仓库或作为新的受控 JSON 快照提交，本节只同步结论。

没有生成生产策略头文件，模型锁和生产代码未因本次研究改变。当前受控头仍是 `calibrated = false`，语义候选分支关闭，关键词匹配仍独立工作。两次正式 holdout 的失败状态继续有效，相关性发行验收未通过。
