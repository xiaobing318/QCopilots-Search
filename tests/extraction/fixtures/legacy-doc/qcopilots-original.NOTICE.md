# 原创 Word 97 文档夹具

`qcopilots-original.doc` 是为 QCopilots Search 编写的独立测试文档，使用已安装的 Microsoft Word 保存为 Word 97 二进制格式。没有读取现有用户文档。保存前启用了 Word 的 `RemovePersonalInformation`，正文仅包含以下原创测试文字。

```text
QCopilots Search original legacy document fixture.
The community workshop repairs a wooden chair by tightening loose joints.
中文测试：社区维修活动修复木椅。
```

文档及测试文字遵循仓库 MIT 许可证。Microsoft Word 程序和字体不随该测试夹具分发。
